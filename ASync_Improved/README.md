# ASync multi-page prototype

Run `npm install` then `npm run dev` and open http://127.0.0.1:8000.

Navigation now uses distinct HTML files: index.html, friends.html, dating.html, communities.html, messages.html, features.html, signup.html.

Demo-only: profile matching and chat are local browser simulations, not real accounts or network messages.


## Visual identity update
The site now uses a shared teal, blue, and violet social-platform theme, a connection-network hero graphic, and balanced friendship/dating language. All seven HTML pages remain separate.
